# Jesús Rodríguez Web Portfolio

## Project Overview

This is the portfolio website for Jesús Alfredo Rodríguez Pérez, a seasoned Full Stack Developer with over 13 years of experience in web technology. The site showcases his expertise in frontend and backend development.

## Project Structure

### Main Components
- **Home Page**: `src/components/home.tsx`
- **Layout System**: 
  - `src/app/layout.tsx` (Root layout)
  - `src/app/[lang]/layout.tsx` (Language-specific layout)
  - `src/app/[lang]/page.tsx` (Main page handler)
  - `src/components/layout/standard-page.tsx` (Standard page wrapper)
- **Navigation**: Header, Footer, ScrollToTop components

### Data Files
- **Skills**: `src/data/skills.ts` - Contains backend and frontend skills data
- **Services**: `src/data/services.ts` - Contains service descriptions for frontend/backend/cloud/mobile development

## Technical Details

### Architecture
The project follows a layered architecture with:
1. App layer (`src/app`) - Next.js routes and pages
2. Components layer (`src/components`) - UI components organized by function
3. Data layer (`src/data`) - Static data files
4. Models layer (`src/models`) - Type definitions

### Key Features
- Multi-language support (English/Spanish)
- Responsive design using Bootstrap grid system
- SEO optimization with metadata
- PDF CV download functionality
- Contact form access

## Development Setup

This is a Next.js application using TypeScript and SCSS. The site includes internationalization support and responsive design features.
